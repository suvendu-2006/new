# Excellence Academy Website

A modern, responsive education website featuring glassmorphism design, smooth animations, and interactive elements.

## 🌟 Features

- **Dark/Light Mode Toggle** - Switch between themes with a beautiful floating button
- **Responsive Design** - Works perfectly on mobile, tablet, and desktop
- **Glassmorphism UI** - Modern frosted glass aesthetic
- **Smooth Animations** - GSAP-powered scroll animations
- **Interactive Elements** - Clickable phone numbers, emails, and course cards
- **Horizontal Faculty Scroll** - Smooth scrolling faculty member showcase

## 🎨 Sections

- **Hero** - Eye-catching landing section with gradient mesh background
- **Why Choose Us** - Bento grid layout highlighting key features
- **Faculty** - Horizontally scrollable faculty member cards
- **Courses** - Interactive course cards with call-to-action buttons
- **Contact** - Full contact information with social media links

## 🚀 Quick Start

Simply open `index.html` in your browser to view the website.

### Running a Local Server

```bash
python3 -m http.server 5555
```

Then access at: `http://localhost:5555`

## 📱 Mobile Access

To access on mobile (same WiFi network required):

1. Start the server on your computer
2. Find your local IP address
3. Access from mobile: `http://YOUR-IP:5555`

## 🎯 Technologies Used

- HTML5
- CSS3 (Glassmorphism, Animations)
- JavaScript (ES6+)
- GSAP (GreenSock Animation Platform)
- RemixIcon (Icons)
- Google Fonts (Inter)

## 📞 Contact Features

- **Phone Numbers**: Clickable tel: links
- **Email Addresses**: Clickable mailto: links
- **Course Cards**: One-tap call to admissions office
- **Social Media Dock**: MacOS-style animated social icons

## 🌈 Theme Toggle

Click the floating button in the top-right corner to switch between:
- **Dark Mode** (default) - Sleek dark theme with royal blue accents
- **Light Mode** - Clean, bright theme

Your preference is automatically saved!
